# 剧集规划节点：画布主题统一与快速编辑布局优化

实施日期：2026-11-22。基线：`custom` / `63a64c8`。本次针对剧集规划摘要与单条快速编辑的视觉/交互，不调整剧情草案协议、SQLite schema、工作流生成状态机与视频链路。

## 1. 交互与视觉规范

- **全局设计系统**：复用 `canvasThemes[useThemeStore().theme]` 的 `node.fill` / `node.panel` / `node.text` / `node.muted` / `node.stroke`、`toolbar.activeBg` / `toolbar.panel` 等既有颜色，不新增写死的浅色/深色调色板；颜色随用户在应用中切换浅色或深色主题立即更新。
- **摘要卡**：上方使用小型书本/分镜标识、标题、当前“已确认/草案”状态及轻量刷新图标；次行显示“已规划 X 集 · 已确认 Y 集”和原生可访问的版本选择。主要内容为带圆角边框的内嵌信息块，突出当前集、标题、概要和位置；上一条/下一条调整到信息块上方的小型导航，不再挤占底部操作区。长摘要在区域内按需滚动，不强行撑高节点。
- **低摩擦草案入口**：已有草案、当前在确认版本时，点击“快速编辑请切换至「草案」”直接切换，确认数据继续只读；摘要刷新不自动清空用户选择的草案版本。
- **底部操作**：草案中提供“快速编辑”与“打开完整编辑器 ↗”并排操作，确认时只保留完整编辑入口。按钮颜色、圆角、对比度、禁用态与焦点轮廓复用节点主题。
- **快速编辑**：分为顶部当前条目/脏状态、中央可滚动字段区、底部固定按钮区。剧集编辑限“本集标题 + 剧情概要”，镜头编辑限“画面描述 + 时长”，避免正文或历史编辑器进入画布。长文本区域可滚动，显示实时字数；表单禁用画布滚轮缩放；支持 Ctrl/Cmd+Enter 显式提交。
- **保存/冲突保护**：未改动 `entry-draft`、`shot-draft` 的 `expectedDigest`、`operationId`、`commitAssistantCanvasGraphWithSaveBarrier` 写入路径；只有点击保存才写入。修改字段时清除旧的错误提示与旧提交操作 ID，不影响已冻结的 CAS digest。冲突仍保留本地输入，并提供显式重新读取最新草案入口。

## 2. 兼容范围

- `drama-node-summary-card.tsx`：剧集与分镜摘要共用主题化卡片结构；`data-drama-summary-kind` 与 `data-drama-card-theme` 仅供只读测试观察。
- `drama-node-quick-editor.tsx`：保留懒加载，继续复用同一 Indexed CAS 事务；`data-canvas-no-zoom` 避免在输入区域滚动时误缩放画布，`position/total` 仅展示当前选择位置。
- 页面级完整工作区、历史/候选、ComfyUI 媒体绑定和自动生成链路不变。首次载入仍请求摘要索引与选中单条，快速编辑组件仅在点击后加载。

## 3. 验证

- 单元测试新增：浅色/深色实时主题切换，切换不会新增后台请求，剧集上一条/下一条与编辑深链、确认版一键切草案，以及固定保存栏、输入脏状态/无隐式写入。原有 digest CAS、冲突保留与镜头保存测试全部保留。
- `npm run test:drama-p3`：12/15 Node PASS（3 项 ComfyUI 实机测试按默认环境跳过），33/33 Vitest PASS。
- `npm run test:drama-p1-browser`：真实 Chrome **105/105 断言 PASS**，新增画布主题颜色、信息分区、固定操作区与编辑容器尺寸约束检查；确定性 mock，不请求真实在线模型。
- `npm run typecheck` 与 `npm run build`：通过。

- 200/100/50 生产构建 Chrome 冒烟：compact Graph 63,559B，`totalApiRequests=50`、`scopedRequests=25`，工作区关闭后新 runs 请求 0；平移 P95 11.8–17.6ms，缩放 P95 17.7–23.6ms，Long Task 0。原有严格 P95≤18ms 目标仍有未达标轮次，不能归功于 UI 重排。

## 4. 性能与交互边界

新卡片仍仅挂载摘要组件，不因 hover/选择/缩放自动实例化完整编辑器、视频配置或历史 Tab。主题色通过当前 UI 的持久主题 Store 读取，不引入每帧 JSON.parse 或新轮询。P3.4b5 生产缩放 P95 阻塞项仍需独立处理，本轮视觉优化不声称解决全部性能目标。
