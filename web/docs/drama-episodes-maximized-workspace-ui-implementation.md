# 剧集规划最大化工作区：主题统一、分栏编辑与操作区优化

实施日期：2026-11-22。前置提交：`1bd15d3`（剧集规划画布轻卡及快速编辑样式统一）。本次针对页面级 **剧集规划完整工作区**，兼容原分镜配置页面，不修改后端数据结构、模型/ComfyUI 生成协议或 Indexed CAS 的写入路径。

## 界面设计

- **最大化 Modal**：工作区采用 `canvasThemes[useThemeStore().theme]` 实时订阅浅色/深色主题。标题由小型 Book 图标、剧集规划标题、所属工作区标识组成。Modal 内容、标题栏、关闭图标、Tab、提示面板、未保存确认弹窗复用画布的 `node.fill / panel / stroke / text / muted` 和 `toolbar.activeBg`，原版 `color` 参数保留为兼容入口，不再另建主题。
- **工作区 Tab**：横向可滚动而非强行换行，各页保留原有准确标签“剧集编辑 / 分页与单条 CAS / 生成候选 / 影响与历史”，分镜额外保留“视频配置”；使用 icon + 当前页选中状态，加入文字说明与独立内容容器。只挂载当前 Tab，继续复用原本的导航 dirty guard，关闭时确保待保存表单不丢失。
- **左侧剧集目录**：宽屏显示每集编号、名称、概要和选中强调；目录单独滚动。窄屏布局改为上方目录/下方编辑内容，保持 min-height 限制，避免一个过长列表把底部操作栏挤出可视区。切换集数仅切换本地选择，编辑仍只更新当前 `episode.id`。
- **右侧分区编辑**：顶部标注当前集和场次/事件计数；标题与目标时长使用并列两栏；“剧情梗概 / 剧情事件 / 本集结尾”保留足够的行高并允许 textarea 自主滚动；“场次规划”改为默认折叠的场次卡，按需展开后可编辑场次名、来源段落、稳定事件引用，仍支持添加场次、拆成两场、并入上一场；最下方是原文出处的按需折叠面板。保留事件稳定 ID 归一化处理逻辑与旧行号引用预警。
- **底部业务操作**：目标集数独立呈现，明确只影响下一次完整规划的生成目标；校验剧集、重跑范围、生成候选与确认阶段集中到主题化的固定操作区，减少与正文混排。实际生成、确认、禁用与错误反馈仍调用现有回调/接口。
- **局部 CAS 页**：剧集独立存储分页浏览的条目详情、可编辑标题/正文、批量暂存区及保存按钮同步画布色板，不改变分页大小、草案 witness、digest 冲突或批量提交顺序。

## 数据与业务不变量

1. `DramaEpisodeFields` 仍通过 `onChange(episodes.map(...))` 更新当前选中条目，其他集保持原引用/数据；章节原文、事件和场次结构依旧以原有 JSON shape 保存。
2. 最大化工作区仍只在显式点击后加载，剧集/分镜摘要节点不挂载完整编辑器；分页与单条 CAS 只在对应 Tab 激活后发起查询。
3. 未提交局部草案仍有保存、放弃与继续编辑三选项。CAS 保存异常时，面板保持原 Tab 与用户输入，不能在失败时静默关闭或切换。
4. 视频配置、镜头批量生成和分镜节点不因剧集规划改版而被自动提交或覆盖。
