# 剧集规划工作区：生成候选与影响历史页交互优化

实施日期：2026-11-22；基于 `custom` / `f326f00`。

## 目标与效果

最大化的剧集规划面板中，原先“生成候选”仅有堆叠运行详情，且“影响与历史”需点“历史版本”另开 Modal。此次改为：

- **生成候选**：增加统一主题的摘要信息栏（运行总数、待采用数、引导说明）、无记录占位、圆角可折叠运行卡；标题突出剧集范围及当前 `run.status`（ready/running/adopted/failed 等）；展开后显示候选剧情、可用操作及错误信息。复用原有请求、轮询、取消/重试、预览与采用业务逻辑；分镜配置的候选差异卡也继承同套设计。
- **影响与历史**：打开 Tab **直接显示历史版本列表及预览**，同时在左侧展示“上游影响”面板；窄屏自动改为上下排列。历史面板不再需要第二层对话框；进入该页自动选中最新版本及加载实际快照详情，仍支持**保存快照、删除、恢复草案、查看当前草案/已确认版本**。影响面板不再点击折叠开关才读取，进入 Tab 就发起一次认证 GET，提供刷新入口。
- **主题一致**：工作区嵌套表单中的 Ant Design Button/Input、候选卡、预览、版本列表、边框与文本色，统一使用 `canvasThemes` 的浅色/深色变量；无独立的一套固定颜色。保留原有最大化窗口、关闭行为和版式。
- **按需加载**：只有在工作区明确进入历史页后才执行版本列表 GET 和依赖 GET，切走历史页卸载预览；Run 列表继续只在候选页或真实生成过程中轮询，避免历史页额外发起后台任务。

## 代码契约

- `canvas-text-versions-modal.tsx` 为现有版本查看/恢复 UI 增加 `inline` 展示模式；原 Modal 路径及操作 API 不变。两种模式**共用同一份交互正文和保存/恢复代码**，并由外层主题 ConfigProvider 提供样式。inline 模式默认展示最新历史快照，而普通弹窗保留原默认预览。
- `drama-creative-workspace.tsx` 新增 `onTabChange` 和 `renderHistoryPanel`，只有成功通过原有 **dirty CAS 导航屏障**时才触发父页面切换回调；历史页采用左侧影响信息卡、右侧版本面板的自适应布局。
- `pages/canvas/project.tsx` 利用已有 `textVersionsNodeId / versionsRefresh / saveTextVersion / deleteTextVersion / restoreTextVersion` 状态和回调接入内嵌历史；共享同一受认证的历史 API，无复制的保存实现。普通节点仍使用历史 Modal。工作区关闭或离开历史时清除与当前创作节点相关的版本查询状态，避免留下额外弹窗。
- `drama-pipeline-node-panel.tsx` 的工作区历史页隐藏原“历史版本”弹窗按钮，自动读取上游影响。非工作区的“检查上游更新”折叠入口保持兼容。候选卡只做展示优化，未改变采用、差异冲突保护及媒体生成协议。

## 内嵌历史高度填充修复（2026-11-22）

用户反馈最大化窗口内历史版本区域只占据约半个编辑高度。原因是最初引入 `inline` 时保留了独立 Modal 的高度：内嵌历史正文硬编码 `min(550px, calc(100dvh - 225px))`，详情布局另有 `md:h-[min(500px,62vh)]`，工作区上层也没有给历史分栏完整的剩余高度。

修复后的样式约束：

- `drama-creative-workspace.tsx`：只在“影响与历史”页采用 `flex flex-col overflow-hidden` 的可用高度容器；内部两栏自适应网格设置 `h-full / min-h-0 / flex-1`，宽屏左右并列、窄屏上游影响与历史版本按 1:2 比例分配；历史版本标题固定，历史主体占满其余空间；左侧影响区按需滚动。
- `canvas-text-versions-modal.tsx`：仅 `inline=true` 时将正文高度改为 `100%`，历史列表及预览网格占满父容器（移除旧的 500/550px 限制），两侧拥有独立 `overflow-y-auto` 滚动条；非内嵌 Modal 的原有固定高度/响应式行为完全不变。
- 新增真实 Chrome 的 DOM 尺寸断言 `episode_history_fills_available_workspace_height`：检查工作区内容底部与历史网格底部对齐、历史主体/内嵌容器/版本正文高度连续填满，并验证两列预览的滚动容器。真实 Chrome **127/127 PASS**，P3 前端 **41/41 PASS**，P2 **74/74 PASS**，TypeScript 与生产构建通过。隔离测试期间真实模型请求 **0**。

本修复不改变历史版本 API、保存/恢复行为，也不影响 P3.4b5 严格缩放性能目标。

## 左栏空状态滚动条与宽度精简（2026-11-22）

- 用户反馈：上游影响没有实际条目时仍出现竖向滚动条，且左栏挤占历史版本预览空间。
- **原因**：原网格左栏宽度按照 `0.8fr : 1.7fr` 分配，实际会占约 32% 宽度。上游影响区本身被网格拉伸到最大高度，并直接挂载 `overflow-y-auto`；此外空的 `impact` 对象也会渲染“细粒度影响预览”的边框和较长说明，使窄栏容易溢出。
- **修复**：宽屏左栏限定 `220–260px`（常规最大化视口约 260px），右栏获取所有剩余宽度；保持窄屏上下排列。左侧 `section` 负责定界高度，真正滚动的是内容尺寸自适应的内部 `data-drama-impact-scroll`，通过 `max-height:100%`、`overflow-y:auto`、`scrollbar-gutter:auto` 实现无溢出时不预留槽、不显示滚动条，长内容才滚动。依赖分析确实没有变更/关联条目时，只保留当前版本状态，不渲染空的细粒度影响详情与长说明。
- **兼容性**：不改变后端依赖计算、历史版本保存/恢复、候选生成、CAS、灰度主题、历史预览高度填充及进入/退出 Tab 的读取时机。
- **验收**：工作区单测补充内容滚动器约束；真实 Chrome 验证左栏像素宽度范围、真实无影响时 `scrollHeight≈clientHeight` 且视口内无冗余滚动条，模拟长列表可滚动、历史仍撑满。真实 Chrome **129/129 PASS**（包含实际空数据无滚动、模拟长列表可滚动、左栏宽度 ≤270px 及历史高度填充）；P3 前端回归 **41/41 PASS**，P3 Node **12/15 PASS**（3 项真实 ComfyUI 测试按默认环境跳过），类型检查和生产构建通过，真实模型请求 0。

## 工作区 Tab 描述改为 Tooltip（2026-11-22）

- 将剧集规划／分镜配置最大化面板的每个 Tab 下方通用说明行移除，减少一层固定布局占位，内容区直接接在 Tab 导航下方；各 Tab 的原说明文字保留且迁移为对应按钮的 Tooltip。
- Tooltip 采用每个 Tab 内部独立状态的轻量 Portal，支持鼠标悬停与键盘焦点，在导航滚动容器之外渲染以防裁切，也不因鼠标移动重新渲染完整编辑器；随 `canvasThemes` 的浅色／深色主题改变背景、边框、文字颜色。导航按钮保留 `aria-description`，显示时增加 `aria-describedby`，供辅助技术读取。
- 未保存草案提醒不属于 Tab 说明，仍仅在 `pendingCount>0` 时出现；切换 Tab、分页 CAS 保存冲突保护、历史页独立滚动与异步加载逻辑全部不变。
- 工作区专项验证全部剧集/分镜 Tab 的 Tooltip 文案、键盘聚焦时独立 Portal 挂载与失焦卸载、无常驻说明行和未保存提醒保留；真实 Chrome **132/132 PASS**，检查说明行消失、所有 Tab 说明属性、模拟 React 鼠标悬停后主题提示出现且不切换 Tab。TypeScript、P3 前端 **42/42 PASS**、生产构建通过；真实在线模型 POST 0。
