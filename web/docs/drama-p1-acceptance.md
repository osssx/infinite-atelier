## 本轮发现并修复

canvas-text-versions.mjs 之前使用 JSON.stringify 比较上游依赖。SQLite 往返后字段序列化顺序可能变化，导致内容相同的依赖误判为“资产定义变化”。在仅确认新参考图时，这会错误更新资产定义的确认修订 ID。

现在使用已有的 stableJson 进行规范化比较。集成测试使用真实故事→资产连接与参考图的两次发布，防止回归。

## 验收边界

本轮使用确定性模型替身，不发送在线模型请求，以便稳定验证确认、冲突与重试语义。ZIP 验收使用真实 SQLite、CAS 和 ZIP 导入导出，而非模拟文件。前端基于 Vitest 验证 Config 构造与迁移，但尚未执行真实浏览器逐按钮操作、线上模型调用或真实 ComfyUI 媒体生成。

因此，本次结果属于 P1 业务契约自动化验收；真实环境的用户操作验收需另行记录，不能宣称已通过。
