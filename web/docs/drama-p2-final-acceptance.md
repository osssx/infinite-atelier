### 新服务端接口

- `GET /api/v1/projects/:id/drama-pipeline/sequence-migration?nodeId=...&episodeId=...`：只读给出各旧镜头可迁入的新场次、状态和摘要。
- `POST /api/v1/projects/:id/drama-pipeline/sequence-migration`：按指定镜头逐项显式迁移，目标归属和乐观冲突校验在事务中完成。
- `POST /api/v1/projects/:id/drama-pipeline/asset-candidates/adopt`：按人工资产候选决策跨分镜草案与资产槽位原子合并。
- 旧 `drama-pipeline/runs`、`runs/:id/preview`、`/adopt`、`/retry` 与影响报告端点保持；原有 JSON 写入路径与前端 Agent 草案入口兼容。

无新 SQLite Schema 迁移。历史确认/Run 修订、媒体 CAS 及 ZIP 读写路径保留。旧 `events`、没有事件 ID 或段落/场次锚点的旧项目可逐步补齐。

## 通过范围与明确边界

通过条件按**P2 技术功能与持久化契约**验收，不等于在线模型创作质量、真实 ComfyUI 图生视频或 P3 视频连续性验收。P2.3–P2.6 的新 UI 使用 TypeScript 检查并经带授权 HTTP 服务测试，但新增界面的完整鼠标交互尚未有独立真实 Chrome P2 端到端专项脚本；已有真实 Chrome 主要验证 P1/候选差异入口。模型使用确定性夹具而非付费真实在线渠道。提交代码不会重启用户正在运行的后端；正在运行的旧进程要使用新接口需正常重新启动。

对低置信映射继续采取保守策略：同名重复事件、段落拆分多继承、场次一对多和老版本美术来源缺失均需人工选择或核对，不自动改写已确认版本。跨项目共享资产、真实媒体输入/首尾帧和大项目性能属于第三期或后续规划，不纳入第二期完成声明。
