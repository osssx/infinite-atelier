# 剧集/资产/分镜流水线 P2 第一轮：细粒度依赖与影响预览

日期：2026-11-21。P1 已于 af5b2fe 完成技术闭环。本次是 **P2 的第一轮可验收增量**，不是 P2 全部交付完成。

## 本次实施

1. **新依赖快照（不更改 SQLite schema）**：\`dramaDependencies\` 在资产条目之外记录其各个变体的独立 digest，在剧集条目之外记录各个场次的独立 digest 与基础字段的 digest。仅当有新版快照时按变体、场次精确判断；旧快照没有子条目摘要时采用整资产、整集的保守范围。媒体参考图快照在采集时深拷贝，防止草案原地修改导致确认快照被别名污染。
2. **场次编辑**：\`DramaEpisode.sequences[]\` 增加可选 \`sourceRefs\` 和 \`eventRefs\`；面板允许编辑场次段落锚点和勾选同集剧情事件。后端校验其为字符串数组，原有只有 \`id,title\` 的场次仍正常读取。剧集 \`sourceRefs=[]\` 也显示可编辑入口。现阶段 \`eventRefs\` 使用剧情事件文本匹配，编辑事件文本后需核对引用，后续应考虑为事件增加稳定 ID。
3. **只读影响预览**：\`GET /api/v1/projects/:id/drama-pipeline/dependencies?nodeId=...\` 保留原有 \`status,changes\`，新增 \`impact\`：
   - \`assetIds\`、\`episodeIds\`、\`sequenceIds\`（格式 \`episodeId/sequenceId\`）、\`shotIds\`；
   - \`mediaShotIds\`：只因参考图槽位变化而需复核媒体输入的镜头，**不会误标为分镜文本变化**；
   - \`configIds\`：需要核对的视频 Config，区别纯文本/独立人工首帧；
   - \`needsReview\`：缺少旧引用、媒体变更无槽位差异、断连、视觉设定、原文拆并无法明确定位等保守提示；
   - \`pending\`：故事已确认更新，但剧集或资产还没重新发布时可能波及的下游剧集、场次、镜头和 Config。**pending 不改变分镜当前确认有效性**。
4. **前端**：四类节点的“检查上游更新”面板展示实际影响 ID 和待确认上游传播信息。没有新的自动写入、批量覆盖或隐式生成。继续使用已有的按集/场/镜候选入口及 Config“采用所选更新”入口执行实际修改。

## 验收矩阵

在 \`web/\` 运行：

    npm run test:drama-p2
    npm run test:drama-p1
    npm run typecheck

新增 \`server/backend/drama-impact.test.mjs\` 验证：
- 同一个场景供两集复用不同变体，更新蓝色参考图只影响蓝色镜头/引用其图片的视频 Config，不影响红色变体或人工首帧；
- 变体定义更新仅影响使用它的镜头；
- 某集场次修改不影响另一个场次/其他集；
- 段落修改、拆分后稳定 ID 与旧 \`sourceRefs\` 映射正确，旧引用显示待核对；
- 段落变化经尚未确认的中间节点传播为待确认警告，分镜本身保持 current；
- 老版本快照、没有引用的老剧集、仅顺序改变、只有媒体修订 ID 而缺少槽位签名时均保守处理；
- 真实 SQLite 项目事务中先依次确认故事/资产/剧集/分镜，再仅确认一套场景变体参考图：资产定义修订 ID 保留、媒体修订 ID 独立更新，最终只标记对应镜头/Config；
- 真实 Fastify 授权接口返回影响列表、匿名访问遭拒。

## 已知边界 / 后续 P2 优先顺序

- **本轮不是完整自动更新系统**：当前只预览影响。真正写回仍需用户显式触发当前按集/场/镜生成候选、逐项采用与确认；待增加一体化“选范围采用”的预览/事务入口。
- 当前 \`eventRefs\` 对应事件文本，改名或去重时可能需要人工校对。下一轮应为事件提供稳定 ID，并将修改/拆分/合并场次映射到明确的差异候选。
- 删除资产、重排镜头的细粒度采用策略、共享资产候选合并后的全量引用原子改写仍需专项验收。
- 美术风格修改当前以“待核对”表示，尚未精确关联每个采用特定风格的 Config；应增加独立视觉依赖摘要。
- 已有场次断点重试与部分采用仍需结合变更预览跑跨重启、多集、人工冲突联合验收。

## 安全与兼容

本轮无数据库 Schema 迁移、无用户项目自动改写、无线上模型请求。旧 ZIP、既有画布与旧 Config 仍由原路径读取。不存在确定影响范围的旧数据不会被默认为“无变化”。
