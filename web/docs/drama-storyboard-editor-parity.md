# 分镜配置节点：对齐剧集规划的交互与主题

实施：2026-11-22，分支 `custom`。

## 问题

现有分镜表的镜头描述、时长、景别、机位、动作、对白、来源、场次及场景均为常驻输入框，键入或选择就调用 `onChange` 写入整个 `dramaDraft`；与新剧集规划“默认阅读、铅笔局部编辑、确认／取消”不一致。最大化分镜表沿用普通表单滚动布局，没有镜头目录；工作区视图开关在最大化状态为空容器。

## 交互与布局

- **画布节点**：继续使用已落地的 `DramaNodeSummaryCard` 索引摘要、轻量编辑入口，绝不在画布同时挂载全量分镜表。摘要状态、前后导航、切换草案、最大化入口和浅深主题与剧集规划保持一致。
- **最大化分镜表**：参考剧集编辑的两栏结构，左侧为镜头目录（顶部剧集选择、镜头数、镜头景别与画面摘要，当前镜头高亮），右侧为镜头详情（标题、顺序和时长汇总）。只在选中时渲染当前镜头的字段，列表独立滚动；窄屏上下排列。
- **字段**：镜头时长、所属场次、画面描述、景别、机位／运镜、动作、对白、场景、场景变体默认以只读阅读卡片呈现，标题旁铅笔打开**该字段**编辑。采用 `toolbar.activeBg` 的低强调底色、左侧细线；编辑态使用 `node.fill` 圆角容器、`node.panel` 输入与 `activeStroke` 焦点，显示“编辑中”。空值显示准确占位，不创建空输入。
- **共享确认／取消**：将剧集的 `EpisodeEditActions` 提取为 `DramaEditActions`，两类节点及场次共用紧凑的右对齐 28px 高、68px 最小宽度主次按钮，无额外顶部横线，使用 `canvasThemes` 配色。输入过程**不修改画布或 JSON**；取消不写入；确认后**只更新当前镜头的目标属性**，保留同镜头其余字段和其他镜头。
- **关系与数据校验**：时长必须为正数或留空；场次及场景选择保留未确认旧 ID 的提示；换场景时在同一次确认中清除旧场景变体，避免悬挂关系；若编辑期间该字段被外部改动，禁止提交过期内容并提示重新打开。切换镜头时本地未确认输入随旧字段卸载，不会应用到别的镜头。
- **视频配置**：继续位于原独立 Tab，保留已确认分镜驱动的视频生产参数、参考图、能力检查与批量创建逻辑；这些是媒体执行配置，不与分镜草案字段“确认”混淆。镜头画面描述预览改用与分镜阅读卡片一致的主题底色、细标识线，顶部剧集／镜头选择器在窄屏自动改为单列。最大化工作区不再渲染空的内层分镜／视频切换栏，视频 Tab 自适应滚动。
- **共用页面行为**：最大化窗口标题旁草案／已确认状态、悬停 Tab Tooltip、左侧上游影响与内嵌历史、历史高度填充、生成候选与 Indexed CAS 工作流沿用已有共享实现。

## 代码入口

- `web/src/features/canvas-assistant/drama-storyboard-fields.tsx`：镜头目录与只读/局部编辑表单。
- `web/src/features/canvas-assistant/drama-edit-actions.tsx`：共享主次按钮；`drama-episode-fields.tsx` 改用共享组件，保留原有 DOM 和测试入口。
- `web/src/features/canvas-assistant/drama-pipeline-node-panel.tsx`：分镜与剧集最大化均使用满高布局，按 Tab 展示独立滚动内容，删除分镜工作区空视图切换栏。
- `web/src/features/canvas-assistant/drama-storyboard-fields.test.tsx`：独立镜头编辑回归；`web/package.json` 的 `test:drama-p3` 包含新测试。

## 镜头原文段落 ID 字段精简（2026-11-22）

- 从分镜表（最大化及紧凑模式）的镜头详情和「分页与单条 CAS」中的镜头草案表单移除 **「原文段落 ID（每行一个）」** 字段及对应编辑操作。
- 不删除 `DramaShot.sourceRefs`、旧草案或历史版本中的已有引用。常规镜头编辑通过对象属性合并保留其值；分页 CAS 的 `ShotDraftEditor` 不再将隐藏的 `sourceRefs` 放入变更补丁，防止其他字段保存时隐式覆盖来源引用。
- 资产与剧集场次编辑中的来源 ID 字段不属于此次移除范围。测试验证字段不再渲染，且修改镜头所属场次时原 `sourceRefs` 保持不变。

## 边界

此次修改界面上的**分镜草案字段**，不重写后端 CAS 或媒体 Config 协议，不自动执行模型或 ComfyUI，不把尚未确认的草案当成已确认分镜。P3.4b5 的严格缩放 P95 性能指标仍为单独待验收项，不能因界面通过而宣称性能达标。
